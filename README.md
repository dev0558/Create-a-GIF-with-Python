# 🖼️ GIF Maker with Python

This is a simple Python project that creates an animated GIF using just two image files and under 10 lines of code. Perfect for beginners exploring image processing!

## 📸 Preview

![My GIF](my_gif.gif)

## 🚀 How It Works

We use the `Pillow` library to resize images and the `imageio` library to combine them into a GIF.

## 📦 Requirements

- Python 3.10+
- `imageio`
- `Pillow`

Install the libraries:
```bash
pip install imageio pillow
